# amorphic-mlp

The source of truth for scope and stages is `docs/amorphic-mlp-plan.md`. Each of the plan's "repositories" is a top-level directory here. `amorphic-demo-env/README.md` has the demo walkthrough and real captured output. `docs/guide.md` is the step-by-step guide for newcomers, with output captured from a fresh clone; keep it in step with `./demo` when commands or output change. `./demo tour` (`scripts/tour.sh`) runs stages 0 to 4 with plain-words narration; keep its wording in step with the story.

- Java: one root Gradle build (`./gradlew build`), toolchain Java 21. Projects are `:pricing-calc-core`, `:pricing-calc-service`, `:amorphic-demo-app`, `:inventory-core`, `:inventory-service`, `:governor-core` and `:governor-service`. The app pulls in core as a project dependency, not via mavenLocal.
- Fold-in: `-PfoldIn=true` puts core in the app's runtime classpath. Without it, core is `compileOnly`, and a `local` binding fails at startup (`Bindings`, `AddressTableFailureAnalyzer`).
- Python: `pricing-calc-py` uses uv (`uv run pytest`) on Python 3.12.
- Golden vectors live at `amorphic-demo-env/golden/vectors.json`. Java tests get the path from the `golden.vectors` system property (`GoldenVectors` in core's test fixtures); Python tests get it from the `golden_vectors_path` fixture. The golden set deliberately has no even-digit half-penny cases before v2.1.
- Monorepo tags carry a prefix: `pricing-calc-java/v2.0` (HALF_UP bug) and `pricing-calc-java/v2.1` (HALF_EVEN fix plus `RoundingRegressionTest` from the caught mismatch). `./demo` builds Java images from these tags. Keep `PricingCalcCore.VERSION` and the Gradle `version` in step.
- Hot reload: `ReloadablePricingCalc` swaps routing when `POST /admin/address-table` applies a table. Each table is an evidence generation; late records from an older generation are dropped. Stage changes are live except folding core in or out, which rebuilds the app (agreed design). `./demo apply <file>` pushes a table by hand.
- Inventory: `:inventory-core` (`amorphic-inventory/inventory-core`), plain Java. `Inventory.observe(timeout)` returns `Observed`/`Unavailable`; `ObservedInventory` reads table, `/health` (`HttpHealthProbe`), evidence and `amorphic-demo-env/catalogue.yaml` on every call, storing nothing. The catalogue lists capabilities and tooling (catalogue, inventory, governor); `Tooling` holds the tooling addresses and default placements. Observation is by `/health`, never the Docker socket (agreed design). The app sets JVM DNS caching to 5s/1s so restarted containers are seen quickly.
- Governor: `:governor-core` (`amorphic-governor/governor-core`), plain Java. `RuleGovernor` applies `amorphic-demo-env/governor-rules.yaml` (first match wins) to the inventory, only when it is ready, and proposes a table rendered in the exact stage-file layout (`Tables.render`; tests assert each proposal equals the next stage file). A human approves (`/governor/proposals/{id}/approve`, `./demo approve`); approval is refused if the table generation changed, and fold-in returns `NeedsRebuild`. `Tables.guardHumanOnly` stops it changing the governor/inventory entries. Stage 1 stays manual (2.0 withdrawn). `GovernorHttp` defines the HTTP shapes the app, the service and `RemoteGovernor` share.
- Tooling bindings: the address table's `inventory`/`governor` entries (champion only, `local` or `remote`; no entry means local) route the app's `/inventory` and `/governor/...` per call (`RoutedInventory`, `RoutedGovernor`; `AddressTable.checkTooling`). Remote means `:inventory-service` (reads the app over `HttpSources`) or `:governor-service` (reads the app's `/inventory`, applies via `HttpTableSink`). Stage files hold only pricing-calc; `./demo` keeps tooling entries in `.run/tooling.yaml` and appends them to every table. Only a human moves tooling (`./demo tooling local|remote [inventory|governor]`).
- Stages are 0, 1, 1b, 2, 3, 3b and 4, with one `amorphic-demo-env/addresses/stage-<id>.yaml` each. The stage table in the plan is canonical. Run them with `amorphic-demo-env/demo`.
- App code map (`amorphic-demo-app/src/main/java/dev/amorphic/demo`): `QuoteController` (the one call site, `/quote`, `/evidence`), `pricing/RoutingPricingCalc` (resolver and champion/shadow/canary routing), `pricing/Bindings` (remote/local), `evidence/EvidenceRecorder` (JSON log lines on the `evidence` logger plus counters).
